# Contributing to the nomadnet-alpine project

Welcome, and thank you for your interest in contributing to the nomadnet-alpine project!

Apart from writing code, there are many ways in which you can contribute. Before interacting with this community, read these short and simple guidelines.

## Conduct of Conduct

The nomadnet-alpine project expects all contributors to maintain a reasonable level of decorum. Be respectful, take feedback and critiques in stride, and treat others the way you wish to be treated.

This is an equal opportunity space and hate towards any group or audience will not be tolerated.

## Asking Questions

If you want to ask a question, ask over on the [discussions](https://github.com/danlbarron/nomadnet-alpine/discussions).

## Reporting Issues

If you have found a bug or issue in this project, please report it using the [issue tracker](https://github.com/danlbarron/nomadnet-alpine/issues). Be sure to include details on how to reproduce the bug.

Anything submitted to the issue tracker that does not follow these guidelines will be closed and removed without comments or explanation.

## Writing Code

If you are interested in contributing code, fixing open issues or adding features, please coordinate the effort with the maintainer or one of the main developers **before** submitting a pull request.

Please make sure your code is up to modern practices, and be receptive to feedback about cleaning up code, or changing code style.

## Generative AI Policy

Contributions written using large language models (LLMs) or other generative 'AI' programs are prohibited. LLMs produce errors so frequently and in a way that is so unlike human error that such issues are incredibly time-consuming to spot and fix.

This applies to all nomadnet-alpine related projects and documentation, as well as all submitted issues and discussions in official channels, except in cases where language translation and/or speech recognition technologies are required for communication.
